# Footer

Chiusura della landing page: nome e frase a sinistra, colonne di link a destra, riga finale con licenza e promesse.

- Piatto, separato dalla pagina da una linea `line`: niente rilievo, è lo sfondo.
- Titoli delle colonne in stile `label` maiuscolo e `ink-muted`; link in `ink`, sottolineati al passaggio.
- La riga finale (`bottom`) è il posto per le promesse verificabili: licenza, link al codice, "Niente pubblicità, niente tracciamento" (solo se è vero).
- Su telefono le colonne vanno a capo sotto il nome.

Il consumatore fornisce `brand` (obbligatorio), `tagline`, `columns` e `bottom`; in inglese `navLabel="Site links"`.
